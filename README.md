# レシート家計簿アプリを作る 6か月チャレンジ

**ゴール：スマホでレシートを撮影すると、商品・日付・金額が自動記録され、**
**「今月の卵は何回・いくら買った？」がわかるアプリを自分で作る**

開始日：2026-04-06
ペース：週4回・1回20〜30分

---

## 

```
① スマホでレシートを写真に撮る
② ブラウザにアップロードする
③ AIが自動で読み取る
   →「大根 / イオン / 2026-04-06 / 98円」
④ データが自動で記録される
⑤ 「今月の卵：3回購入 / 合計534円 / 平均178円」が見られる
```
